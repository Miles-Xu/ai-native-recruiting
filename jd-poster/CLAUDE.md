# JD 海报生成流程

> 使用 tips：把 logo、配色、footer 和 JD 正文换成你自己的即可（改法见下方「设计规范」）。

## 这个目录是干嘛的

把一份 JD 文本变成一张可直接发朋友圈/公众号/社群的**招聘海报 PNG**。做法是单文件 HTML 模板 + Playwright 3x 高清截图，好处是排版全部可控、可复现，改一次模板所有海报统一升级——比用 PS 一张张画快得多。

难点不在生成，在**排版质量**：海报是窄幅长图，bullet 文字长短不一，宽度选错就会出现"第二行只剩两三个字"的短尾，观感立刻掉档。所以这套流程的核心是**用脚本量化短尾、扫出最优宽度**，而不是靠肉眼反复试。

## 前置依赖

```bash
py -3.12 -m pip install playwright
py -3.12 -m playwright install chromium
```

每次开工先起本地服务（脚本走 http 而非 file:// 协议，避免资源加载问题）：

```bash
py -3.12 -m http.server 8877 --directory .
```

## 工作流

### Step 1｜把 JD 内容填进模板

编辑 `jd_poster.html`，**只改内容，先不用管宽度**（宽度由 Step 2 定，脚本会动态注入）。

模板有两种正文结构，按 JD 形态选：

| 结构 | 用法 | 适用 |
|------|------|------|
| `.lane` 卡片（`.lane-1/2/3`，带序号圆点 + 中英文小标题） | 一个岗位含多个并列方向 | 「三个方向同时开放」这类合并 JD |
| 普通 `ul li` section | 岗位职责 / 任职要求 / 加分项 | 常规单岗位 JD |

两者可混用（如职责用 lane 卡片、要求用普通 ul）。要点：
- **不删减 JD 原文**——海报是对外承诺，不要为了排版好看砍内容；内容太长就加宽度或拆两张
- 重点词用 `<b>` 包住，会自动上品牌色
- 标题 `<h1>` 里可加 `<span class="sub">` 作副标题

### Step 2｜扫宽度，定最优值

```bash
py -3.12 scripts/sweep_width.py jd_poster.html 380,400,420,440,460,480
```

输出示例：

```
w= 380 h= 1420 h1行=2 短尾=3 次短=1 末行均值=52.1%
w= 440 h= 1240 h1行=1 短尾=0 次短=2 末行均值=68.4%
w= 480 h= 1180 h1行=1 短尾=2 次短=1 末行均值=61.0%
```

**判据（按优先级）：**
1. `h1行=1` —— 标题必须一行放下，2 行直接淘汰（放不下就缩 `h1` 字号再扫）
2. `短尾=0` —— 短尾指某条 bullet 换行后末行填充率 <30%
3. `末行均值` 大的更好 —— 说明多数 bullet 把行宽填满了

上例选 **440**。

参考区间（内容量 → 起扫范围，不是硬规则）：长 JD（5+ 条长 bullet × 3 section）440-480；中等 JD（3-4 section）390-420；短 JD（2 section）360-380。

定了宽度后，把值写回 HTML 的两处——`<meta name="viewport" content="width=XXX">` 和 `body { width: XXXpx; }`。脚本虽然会注入宽度覆盖，但写回去才能直接在浏览器里预览到同样效果。

### Step 3｜出图 + 自检

```bash
py -3.12 scripts/render_poster.py jd_poster.html 440 大模型训练框架工程师.png
```

脚本除了落图，还会打印逐条诊断：

```
440x1240 scrollW=440 -> 大模型训练框架工程师.png
  [H1] 1行 末行82.3%  大模型训练框架工程师
  [LI] 3行 末行71.5%  负责大模型预训练框架的研发
  [LI] 2行 末行24.1%  要求精通 C++/CUDA        <-- 短尾
```

**交付前必须过这四条：**
1. `h1` 是 1 行
2. `scrollW` 等于宽度——不等说明有内容溢出，出图会带右侧白条
3. 没有 `<-- 短尾` 标记
4. 底部没有多余空白（看图确认，脚本测不出）

**任一条不过就调宽度重出，不要直接交付第一版。** 这条是硬规则——第一版几乎总有短尾。

## 设计规范

- 品牌色：蓝 `#1450dc` → 青 `#00b4c8` → 绿 `#00c882`（顶栏/底栏/标签/lane 卡片左侧色条/加粗字均取自这三色）
- 背景：左上淡蓝 → 右下淡绿渐变 + 两个装饰光圈
- Logo：header 左侧内嵌 SVG，高度 26px
- 标签：右上「热招岗位」，品牌渐变底 + 白字
- 底部固定信息块：工作地点 + 简历投递邮箱（如需加微信，照 `.footer-row` 结构再加一行）
- 底部 slogan 居中小字

## 约定

- 一 JD 一版，**不复用上一次的宽度**——内容变了最优宽度就变了
- 输出 PNG 放本目录（`examples/` 只放对外范本）
- 临时/调试产物放 `_tmp/`
- 改模板前先备份：`copy jd_poster.html jd_poster.html.bak.YYYYMMDD`

## 文件

- `jd_poster.html` —— 海报模板，所有 JD 共用这一个文件，每次替换内容
- `scripts/sweep_width.py` —— 扫宽度选最优（只测量不出图）
- `scripts/render_poster.py` —— 按宽度出 3x 高清图 + 逐条短尾诊断
- `examples/` —— 范本海报，视觉参照
