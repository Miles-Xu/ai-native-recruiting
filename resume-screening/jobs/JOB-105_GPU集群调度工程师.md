# JOB-105 GPU 集群调度 / IaaS 工程师

> 虚构示例岗位（烛龙智能），JD 画像参考市场公开在招岗位改写。
> 本岗位尚未与用人经理对齐偏好口径（见 `../CLAUDE.md` 岗位偏好段）——这是有意留白，演示"新岗位先有 JD、偏好后补"的状态。

## 岗位职责

1. 参与 GPU 集群资源调度系统的设计与研发，面向 AI 负载构建计算、存储、网络管控体系
2. 开发服务器全生命周期管理工具，参与裸金属/虚拟化资源池管理平台建设
3. 构建资源运营分析系统，推动集群利用率持续优化
4. 参与多云多地域混合算力底座建设，保障大规模集群的稳定性与可观测性

## 任职要求

1. 计算机相关专业本科及以上学历，熟悉 Golang/Python
2. 熟悉 Linux 系统与分布式系统原理，有大规模集群运维或研发经验
3. 熟悉 Kubernetes 生态，有调度器、Operator 开发经验者优先
4. 有 GPU 集群管理、在离线混部、资源利用率治理经验者优先
