# JOB-102 推理引擎工程师

> 虚构示例岗位（烛龙智能），JD 画像参考市场公开在招岗位改写。分 Junior（1-3 年）/ Senior（5 年+）两档。

## 岗位职责

1. 负责大模型推理引擎的研发与性能优化：KV Cache 管理、PagedAttention、Prefill/Decode 分离调度
2. 负责推理服务的延迟与吞吐优化：量化（INT8/FP8/AWQ）、投机采样、算子优化、批调度策略
3. 跟进 vLLM / SGLang / TensorRT-LLM 等开源推理框架演进，评估并落地前沿推理加速技术
4. 与算法团队协作完成新模型结构（MoE、多模态、长上下文）的推理适配与上线
5. 建设推理服务的性能分析与瓶颈定位工具链

## 任职要求

1. 计算机相关专业本科及以上学历，精通 C++/CUDA，熟悉 Python
2. 深入理解 Transformer 推理的两阶段特性与显存管理，有实际的推理优化项目经验
3. 熟悉 vLLM、SGLang 等主流推理框架，有源码级理解者优先
4. Senior 档要求：主导过生产级推理系统的架构设计与优化，有可量化的成本/延迟收益
5. 有 GPU 体系结构、Nsight 性能分析、模型量化部署经验者优先
