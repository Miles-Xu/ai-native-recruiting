# JOB-101 训练框架工程师（预训练 infra）

> 虚构示例岗位（烛龙智能），JD 画像参考市场公开在招岗位改写。

## 岗位职责

1. 负责大模型预训练框架的研发与优化，覆盖数据并行、张量并行、流水线并行、序列并行、MoE 专家并行等分布式策略的设计与实现
2. 负责大规模训练集群（千卡级）上的训练吞吐优化：算子融合、显存优化（ZeRO/重计算/offload）、通信与计算重叠
3. 开发和深度优化 CUDA/通信算子，定位训练性能瓶颈并给出系统级解决方案
4. 负责大规模预训练的稳定性建设：Loss/Grad 异常定位、通信 hang 排查、故障恢复与 Checkpoint 机制
5. 支持多模态模型（图像/视频/音频）预训练的系统落地：长序列、变长数据、负载均衡等训练问题

## 任职要求

1. 计算机相关专业本科及以上学历，扎实的 C++/Python 功底
2. 深入理解 PyTorch 底层机制，熟悉 Megatron-LM、DeepSpeed、FSDP 等至少一种分布式训练框架的源码
3. 有大规模 GPU 集群上的实际训练经验，能量化说明优化收益（吞吐/MFU/显存/稳定运行时长）
4. 熟悉 NCCL 通信原理，有 CUDA Kernel 或通信算子开发经验者优先
5. 有千亿参数级别模型预训练全流程经验者优先
