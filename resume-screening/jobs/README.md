# jobs/ — 岗位库

每个岗位一个 Markdown 文件，文件名格式：`JOB-编号_岗位名.md`。

## 文件格式

```markdown
---
id: JOB-101
title: 训练框架工程师
hiring_manager: 陈默        # 用人经理（可选）
example: true              # 示例岗位标记；你自己的岗位不要带这个字段
---

## 岗位职责
...

## 任职要求
...
```

## 规则

- frontmatter 带 `example: true` 的文件是仓库自带的虚构示例，不参与简历匹配
- 第一次使用时，Claude 会检测到 `jobs/` 里只有示例岗位，主动访谈你并生成你的真实岗位文件
- 岗位的业务侧偏好（用人经理口径、硬门槛、话术）不写在 JD 文件里，统一维护在上一级 `CLAUDE.md` 的「岗位偏好」段——JD 是对外的，偏好是对内的，分开放
- 每次和用人经理对齐后更新偏好段，带日期，方便追溯口径演进
