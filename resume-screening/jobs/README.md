# jobs/ — 岗位库

每个岗位一个 Markdown 文件，文件名格式：`JOB-编号_岗位名.md`。

## 文件格式

```markdown
---
id: JOB-101
title: 训练框架工程师
hiring_manager: 陈默        # 用人经理（可选）
example: true              # 示例岗位标记；你自己的岗位不要带这个字段
---

## 岗位职责
...

## 任职要求
...
```

## 规则

- frontmatter 带 `example: true` 的岗位用于试跑示例；正式筛选时排除
- 已有真实 JD 时直接使用；需要建立岗位文件时，只补充缺失信息
- 岗位偏好（用人经理要求、硬门槛、沟通重点）与 JD 正文分开维护，本示例放在上一级 `CLAUDE.md` 的“岗位偏好”段
- 示例评分和偏好不自动用于真实岗位；正式使用前换成自己的要求
- 更新偏好时记录日期，注明替换的旧要求，避免冲突
