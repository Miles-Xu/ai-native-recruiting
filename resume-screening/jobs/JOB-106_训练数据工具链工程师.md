# JOB-106 训练数据工具链工程师

> 虚构示例岗位（烛龙智能），JD 画像参考市场公开在招岗位改写。
> 本岗位尚未与用人经理对齐偏好口径——偏好后补。

## 岗位职责

1. 负责大模型训练数据基建：数据管道、数据加载优化、训练数据 pipeline 建设
2. 负责训练数据格式与存储方案（WebDataset/Sharded 等）的设计与优化
3. 建设模型工具链：格式转换、权重切分合并、跨框架迁移
4. 优化 dataloader 与 checkpoint 的性能与可靠性

## 任职要求

1. 计算机相关专业本科及以上学历，Python/Go/C++ 至少精通两门
2. 有 Ray/Spark 等分布式计算框架的实际使用或开发经验
3. 有大规模数据处理系统或训练数据 pipeline 建设经验者优先
4. 注：本岗位不是 CUDA 算子方向
